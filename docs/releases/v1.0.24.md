# X Lite v1.0.24

This release introduces a dedicated Kotlin security/validation policy module with JUnit4 unit coverage, adds SHA-256 checksum verification (`SHA256SUMS.txt` + verified installer bridge) to the in-app APK updater, surfaces the embedded git commit SHA in Settings, and adds multi-job GitHub Actions CI, CodeQL scanning, and repository documentation matching open-source standards.

## Changes since v1.0.23

- **Shared Security & URL Policy (`XLitePolicy.kt`)**: Extracted scheme/host allowlists, transaction ID checks, semver non-downgrade comparisons, GitHub Release `SHA256SUMS.txt` parsing, image candidate URL rewriting, and image magic-header detection into pure-JVM unit-testable helpers shared cleanly across `MainActivity.kt` and `TwitterBridge.kt`.
- **SHA-256 Verified In-App APK Updater (`TwitterBridge.kt`, `index.html`)**: Added `installApkUpdateVerifiedAsync(url, expectedVersion, expectedSha256)` with automatic `SHA256SUMS.txt` digest lookup and cryptographic verification prior to package installation, while retaining full backwards compatibility with `installApkUpdateAsync`.
- **Build Stamp Visibility (`build.gradle.kts`, `index.html`)**: Exposed `BuildConfig.GIT_SHA` via `TwitterBridge.getAppVersionInfo()` (`sha`) and rendered it beside the installed APK build in **Settings → Version & System Info**.
- **Automated Kotlin & Web Test Coverage (`XLiteUnitTest.kt`, `scripts/verify-assets.cjs`, `post-actions.test.cjs`)**: Added 7 JUnit4 Kotlin tests, static script/version/XML/secret verification (`verify-assets.cjs`), and Node regression tests for the verified updater bridge.
- **CI, CodeQL & Open-Source Repository Polish**: Added `.github/workflows/ci.yml` (`web-suite` + `android-suite` running `testReleaseUnitTest lintRelease assembleRelease`), `.github/workflows/codeql.yml`, `SHA256SUMS.txt` release artifacts, `LICENSE` (MIT), `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and live-rendered UI screenshots.
