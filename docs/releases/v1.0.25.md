# Release v1.0.25 — Uncompromised Full-Data Mode & Native Fullscreen Video

- **Full-Resolution `Auto-load previews` Images & Banners (`XLitePolicy.kt`, `MainActivity.kt`):**
  - `rich` mode (`Auto-load previews`) now prioritizes `large` (`webp` / native) ahead of `medium` and `small` instead of capping feed images to `small`, and raises the pass-through byte limit to `2560 KB` (matching `hd`).
  - Profile banners in `rich` and `hd` modes request `1500x500` first, and video thumbnails request `:large` first.
  - High-DPI feed/profile avatars in `auto` mode fetch `_bigger` / `_200x200` through the non-recompressed `rich` proxy instead of low-bitrate thumbnails, with 38px Twitter-style avatar framing.
- **Instant HD Video & Native Fullscreen (`index.html`, `MainActivity.kt`):**
  - Added `WebChromeClient` (`onShowCustomView` / `onHideCustomView`) with edge-to-edge fullscreen custom view container and Android Back handling.
  - `Auto-load previews` defaults `<video>` playback straight to the highest MP4 bitrate variant (`hd_video_url`) with automatic SD fallback and mutual-exclusion playback across timeline videos.
- **Richer Quotes, Expanded Links & Strict Zero-Ads (`index.html`):**
  - Quoted posts render full embedded photos, videos, GIFs, polls, and link cards when `Auto-load previews` is enabled.
  - `entities.urls` shortlinks (`t.co`) expand cleanly to readable destination URLs while stripping redundant trailing quote permalinks.
  - Hardened `isPromotedItem` and REST fallback parsers to block all promoted/sponsored injection formats across feeds, search, profiles, and conversation replies.
