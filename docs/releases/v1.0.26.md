# Release v1.0.26 — Instant Settings Persistence for `Auto-load previews`

- **Immediate Persistence on All Settings Preferences (`index.html`, `TwitterBridge.kt`, `XLitePolicy.kt`):**
  - Selecting **Auto-load previews**, **Tap to load small previews**, **Text only**, or any Profile Picture / Ad Filter / Seen Sync option in **Settings** now saves immediately (`onchange`) without having to scroll down and tap **Save Configuration**.
  - Added synchronous `.commit()` persistence and `XLitePolicy.normalizeImageMode` validation in `TwitterBridge.kt` alongside backwards-compatible OTA caching (`saveConfig` + `pref_image_mode` + `localStorage`) so navigating back (`Home` / `← Settings`), tapping **Refresh**, or cold-restarting the app preserves the selected mode cleanly.
- **End-to-End Verification:**
  - Verified the complete user flow (`tap` -> Settings -> select **Auto-load previews** -> back to Home -> Refresh -> Settings check -> full reload) in Headless Chromium and expanded Node unit tests + JUnit4 coverage.
