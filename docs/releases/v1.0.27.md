# Release v1.0.27 — Plain Video Autoplay, Reddit-Style Threaded Replies, SVG Chrome & Fast Startup

- **Plain Video Container & Muted Scroll Autoplay (`index.html`):**
  - Removed the `.video-meta-row` (`Video · Xs` / `HD`) bar underneath video players so video posts render in a clean, minimal container while still defaulting directly to HD MP4 streams with automatic SD fallback on error.
  - Enabled muted in-viewport video autoplay by default when **Auto-load previews** is active, with mutually exclusive single-video playback, a top-right SVG mute/unmute toggle, and a new **Video Autoplay** setting in **Settings** (`On (muted)` / `Off`) that saves immediately on tap.
- **Reddit-Style Threaded Conversation View:**
  - `parseSingleTweet` now retains `in_reply_to_id`, `in_reply_to_screen_name`, and `conversation_id`, and `buildThreadHierarchy` constructs both the parent ancestor spine above the focal post and nested parent-child reply trees below it.
  - Replies display color-coded vertical guide rails, explicit `Replying to @user` indicators, and collapsible comment branches (`−` / `+ N`).
- **Faster Cold Startup & Scrolling:**
  - Persists compact `ClientTransaction` verification snippets and content-hashed `ondemand.s` key-byte indices (`pref_tx_cache_v1` / `pref_tx_ondemand_<hash>`) across sessions for immediate `0 ms` signed request startup with background refresh and automatic `401`/`403` invalidation recovery.
  - Defers video metadata fetches (`preload="none"` until near viewport via `IntersectionObserver`) so off-screen videos do not compete with feed timelines and images during launch.
- **Monochrome Inline SVG Icons:**
  - Replaced UI emojis across the top header, bottom navigation bar, tweet actions, retweet banner, verified checkmarks, profile location pin, notification icons, and runtime source labels with inline SVG icons.
