# Release v1.0.28 — Community Notes, Pull-to-Refresh, Sticky Tabs, Full-Res Avatars & Mobile Polish

- **Community Notes (`index.html`):**
  - Enabled GraphQL `withBirdwatchNotes` and `responsive_web_birdwatch_note_limit_enabled` flags across feed, search, and thread requests.
  - Added `extractCommunityNote`, `renderCommunityNoteBody`, and `renderCommunityNoteHtml` (capturing outer `birdwatch_pivot` wrappers around `TweetWithVisibilityResults`) to render readable Community Notes with clickable reference links on feed cards, Reddit-style nested replies, and quoted tweets.
- **No Duplicate `@mention` Prefix:**
  - `parseSingleTweet` strips API-prepended hidden reply `@mentions` bounded by `legacy.display_text_range[0]` (`stripHiddenReplyMentions`), and `startsWithMention` suppresses redundant `Replying to @user` context lines when the visible tweet body already opens with `@user`.
- **Viewport Fit & Single Scrollbar Fix (`index.html`, `MainActivity.kt`):**
  - Replaced horizontal overflow traps with `html, body { max-width: 100%; overflow-x: clip; }` (preserving `position: sticky` behavior), added `overflow-wrap: anywhere` on tweet text/links/cards, allowed `.tweet-actions` wrapping without negative edge margins, tightened nested Reddit thread indentation, and disabled WebView horizontal scrollbars and overscroll bounce in `MainActivity.kt`.
- **Full-Resolution Profile Pictures in Auto-Load Mode (`index.html`, `XLitePolicy.kt`):**
  - In `auto` image mode, `renderAvatarHtml` and `renderProfileShell` request original (`orig`) profile avatars with automatic `_400x400` client fallback (`fallbackAvatarImg`), backed by `/profile_images/` candidate fallback (`orig` -> `_400x400` -> `_200x200` -> raw URL) in `XLitePolicy.buildImageCandidateUrls`.
- **Navigation, Pull-to-Refresh & Lightbox Gestures (`index.html`):**
  - Made the `Following` / `For You` / `Offline` tab bar sticky directly under the top header (`position: sticky; top: 52px`).
  - Replaced the static feed `Refresh` button with native-feeling pull-down-to-refresh (`#pullRefreshIndicator`), and added a floating scroll-to-top button (`#scrollTopBtn`) that appears after scrolling down.
  - Tapping the `X Lite` header logo now smoothly scrolls to top (or refreshes when already at top on the feed) without surfacing `"Showing recent cached tweets"`.
  - Added downward-drag swipe-to-dismiss gestures on `#mediaLightbox` (alongside horizontal swipe navigation for multi-photo posts).
- **Search Keyboard Stability:**
  - Added `enterkeyhint="search"` and `blurActiveSearchInput()` when submitting searches, tapping hashtags, and rendering search results so the on-screen keyboard does not reopen or steal focus back to `#searchInput`.
