# Release v1.0.30 — Cross-App Seen Sync (`HomeTimeline` + Impression Bloom Store), Persistent Queues & Zero Repeat Filtering

- **Cross-App Seen Sync to X's Backend Impression Stores (`index.html`, `TwitterBridge.kt`):**
  - Added proactive `flushSeenToHomeTimeline` syncing `seenTweetIds` directly to `POST /i/api/graphql/.../HomeTimeline` (which feeds X's `ManhattanTweetImpressionStore` and cross-device `ImpressionBloomFilter` so posts scrolled in X Lite no longer resurface when switching back to the official X app).
  - Sync flushes automatically at `>= 10` viewed posts, after a `5.5s` reading pause (prebuffering the next page in `prebufferedNextPage.foryou` for zero-lag `Load More` when browsing `For You`), and immediately on `visibilitychange === 'hidden'`, `pagehide`, tab switches (`switchFeed`), and view navigation (`nav`).
  - Prevented `HomeLatestTimeline` (`Following` tab) from draining `pendingSeenTweetIds` (using a non-destructive snapshot instead), and only confirms/removes pending IDs after `HomeTimeline` returns HTTP 200 OK.
- **Persistent Queues & Official `x.com` Web Telemetry Compatibility (`index.html`, `TwitterBridge.kt`):**
  - Persisted both `seenForYouIds` (`2000`-item cap) and unsynced `pendingSeenTweetIds` (`1500`-item cap) across `localStorage` and `AndroidBridge.saveCache`/`getCache` so seen IDs survive app kills until confirmed.
  - Updated `jot/client_event.json` events to include `client: 'm5'`, `component: 'stream'`, `client_app_id: '3033300'`, monotonically increasing sequence numbers/timestamps, `author_id`, and empty-body HTTP 200 handling.
  - Added `origin: https://x.com` and removed duplicate `content-type` headers in `TwitterBridge.kt` (`executeFormPostWithTransactionAsync` and `buildPostRequest`).
- **Retweet Outer IDs, Incremental Viewport Observer & Zero-Repeat `For You` Filtering (`index.html`):**
  - Preserved outer retweet IDs (`outer_id`) alongside unwrapped source IDs (plus quoted tweet IDs and lightbox/video/thread interactions) across `seenForYouIds` and `seenTweetIds`.
  - Updated `initSeenObserver` to observe newly appended tweets incrementally (`[0.15, 0.35]` intersection, `220ms` dwell) without canceling active dwell timers during infinite scroll pagination, and passed accurate `requestContext` (`launch` / `ptr` / `scroll`).
  - Filtered `seenForYouIds` on `For You` initial loads, cache restores, pull-to-refresh, and pagination (`isPaging`), automatically advancing up to 2 cursor pages if every item on a page was already read and bypassing the 5-minute refresh cooldown when cached posts are mostly seen or pending sync IDs remain.
