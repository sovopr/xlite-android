# Release v1.0.32 — Exact Element-Anchored Back Scroll Restoration & Intrinsic Media Aspect Ratios

- **Element-Anchored Scroll Restoration Across All Views (`index.html`):**
  - Replaced fragile raw-pixel-only `savedFeedScrollY` restoration with element-anchored tracking (`captureViewAnchor`, `findAnchorElement`, `computeAnchorTargetY`) keyed by `[data-tweet-id]` / `[data-quoted-id]` (or topmost visible tweet card fallback) and its viewport `offsetTop`.
  - Restores the exact tapped tweet (or quoted tweet) to the same screen vertical offset even when items above it shift height during `DocumentFragment` detach/re-attach, lazy image loading, `<video>` metadata resets, status banner removal, or `innerHTML` rebuilds across Feed (`Following`, `For You`, `Offline`), Search, Profile, and Notifications.
  - Added user-interruptible multi-pass stabilization (`0ms`, `rAF`, `60ms`, `180ms`, `340ms`) that cancels immediately on user `touchstart`, `pointerdown`, `wheel`, or `keydown` input, plus `window.scrollTo(0, 0)` when entering non-reply-focused threads.
- **Explicit Media Aspect Ratios & Stable Off-Screen Card Heights (`index.html`):**
  - Removed `content-visibility: auto; contain-intrinsic-size: 0 210px;` from `.tweet`, preventing off-screen cards above the viewport from snapping back to `210px` placeholders upon `DocumentFragment` detach/re-attach (`savedFeedNodes`) or lazy render-margin wakeups (the primary source of multi-tweet downward/upward drift on Back).
  - Extracted media dimensions (`original_info`, `sizes.large/medium`, and `video_info.aspect_ratio`) in `parseSingleTweet()` and emitted inline `aspect-ratio` styles on single-photo `.media-grid-1 .tweet-img` and `<video class="tweet-video">` elements to eliminate vertical box collapse when detached or lazy-loaded.
- **Observer Sequencing & `Feed -> Thread -> Profile -> Back` Preservation (`index.html`):**
  - Restores anchored scroll coordinates *before* re-attaching `initSeenObserver`, `initVideoAutoPauseObserver`, and `attachFeedInfiniteScroll` so top-of-feed autoplay/seen observers never fire at `scrollY = 0` prior to jumping back down.
  - Preserved `savedFeedMarkup`, `savedFeedNodes`, and `savedFeedAnchor` across `thread -> profile` transitions so navigating Back from an author profile opened inside a thread returns directly to the anchored feed position instead of reloading `For You` past `seenForYouIds`.
